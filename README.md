## 👨‍💻 About Me

I'm a **Software Engineering graduate** and **Full-Stack Developer** passionate
about building real-world software solutions.

My primary focus is on **MERN Stack development and Flutter**, where I build
modern web applications, cross-platform mobile applications, RESTful APIs,
and database-driven business systems.

I enjoy turning business requirements into practical software solutions,
designing backend architectures, working with databases, and creating
clean and intuitive user experiences.

Currently, I'm working on **Indus Steel Works (ISW)** — a complete warehouse
